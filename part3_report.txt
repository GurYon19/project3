# Part 3: Multi-Class, Multi-Object Detection Report

## 1. Task Overview

Part 3 extends the detection pipeline from single-object to multi-class, multi-object detection.
The requirements are:
- Detect up to K=3 objects per image
- Support at least 2 object classes
- Use the MobileNetV3-Small backbone from Part 1 (pretrained on ImageNet)
- Implement appropriate loss functions and evaluation metrics

We chose 3 foreground classes from PASCAL VOC: **person**, **car**, and **dog**, plus a
background class — 4 classes total.

---

## 2. Dataset

### Dataset Selection: PASCAL VOC 2007 + 2012
We used PASCAL VOC (2007 + 2012 combined) filtered to images containing at least one instance
of person, car, or dog. This gave a rich, real-world multi-object dataset with high-quality
bounding box annotations.

**Class distribution (training set):**
- person: 9,606 instances
- car:    1,163 instances
- dog:    1,054 instances

The severe class imbalance (9:1 ratio of person to car/dog) became a key challenge addressed
throughout training.

**Dataset split:**
- train.json / val.json / test.json — built using tools/build_voc_part3_k3_relaxed.py
- "Relaxed" filtering: images with up to K=3 foreground objects of the target classes

**Preprocessing:**
- Images resized to 448×448 (larger than standard 224 to preserve spatial detail)
- ImageNet normalization: mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]
  Note: Forgetting this normalization was an early bug that severely hurt performance.

**Data Augmentation (training only):**
- Random square crop (scale range 0.60–1.00, retried up to 5 times to keep at least 1 object)
- Random horizontal flip (p=0.5), with bounding box coordinates mirrored accordingly
- Color jitter (brightness, contrast, saturation, hue)
- Gaussian blur

---

## 3. Model Architecture

### 3.1 Baseline: Fixed-Slot Detector with Global Average Pooling (GAP)

The initial architecture followed a straightforward approach:

  MobileNetV3-Small backbone → AdaptiveAvgPool2d(1,1) → [B, 576]
  → MLP head → K×4 box outputs + K×C class logits

Each of the K=3 slots shared the same pooled feature vector. While simple, this design has a
fundamental flaw: because all slots receive identical features, the model cannot spatially
distinguish between different objects in the same image. In practice, slots collapsed —
predicting the same dominant object (usually "person") from every slot.

This architecture achieved mAP@0.5 = 0.354 after fixing the pretrained weights and
normalization bugs described below.

### 3.2 Final Architecture: Spatial Slot Attention

To address the slot-collapse problem, we redesigned the head to give each slot an independent
spatial view of the feature map:

  Backbone features: [B, 576, h, w]
       ↓ 1×1 Conv2d (projects to hidden_dim=512, preserves spatial dims)
  Projected features: [B, 512, h, w]  →  flattened to [B, 512, H×W]
       ↓ Scaled dot-product attention
         K learnable slot query vectors [K, 512] attend to spatial positions [H×W]
         attn = softmax(Q × F^T / sqrt(512))   shape: [B, K, HW]
  Slot features: [B, K, 512]   (each slot attends to a different region)
       ↓ Per-slot MLP (Linear → ReLU → Dropout)
  Output: boxes [B, K, 4],  logits [B, K, C]

Key properties:
- The K slot queries are learnable parameters initialized with small random values
- Each query specializes during training to attend to different spatial regions
- Slot features are independent — no feature sharing between slots
- The 1×1 conv projects from 576 (MobileNetV3 output) to 512 (hidden dim)

This architecture was developed on a dedicated git branch: part3-spatial-head.

## 4. Loss Function

### Hungarian Matching
For each image, predictions are matched to ground-truth objects using brute-force Hungarian
matching (tractable for K=3). The matching cost combines:
  - Classification cost: cross-entropy between predicted class probs and GT labels
  - Box cost: CIoU distance between predicted and GT boxes

Unmatched slots are assigned the background class.

### CIoU Loss (Box Regression)
Complete IoU loss penalizes:
  1. Overlap area (standard IoU)
  2. Center point distance
  3. Aspect ratio consistency
This is more informative than L1 or smooth-L1, especially for multi-scale boxes.

### Classification Loss
Two variants were tested:
- Standard cross-entropy (baseline)
- Focal cross-entropy (final): downweights easy/frequent examples (person) and
  focuses gradient on hard/rare ones (car, dog). Controlled by gamma parameter.

### Total Loss
  L_total = w_cls × L_cls + w_box × L_box
  (w_cls=1.0, w_box=5.0 in all runs)

## 5. Training Configuration

- Optimizer: AdamW (lr=3e-4, weight_decay=1e-4)
- Scheduler: CosineAnnealingLR (T_max=epochs, eta_min=lr×0.01) — stepped per epoch
- Batch size: 32
- Epochs: 30
- Device: Apple MPS (M-series GPU)
- Best checkpoint selected by validation mIoU (mean IoU over matched pairs)

## 6. Methods Attempted & Ablation

### Bug Fixes That Had the Largest Impact

**A. Pretrained weights not loaded (critical bug)**
The argparse flag `--pretrained` used `action="store_true"`, meaning pretrained=False
was the default. All early runs trained MobileNetV3 from random initialization.
Fix: Always pass `--pretrained`. Effect: mAP jumped from 0.15 → ~0.35.

**B. Missing ImageNet normalization in inference**
predict_image() applied TF.to_tensor() but not TF.normalize(), so inference received
un-normalized inputs while training used normalized inputs. This caused erratic predictions
on all test images and video.
Fix: Added TF.normalize() to inference pipeline.

**C. Cosine scheduler stepped per batch instead of per epoch**
The LR scheduler was being called inside train_one_epoch() (per step), causing the LR
to decay to near-zero within the first epoch.
Fix: Moved scheduler.step() to the outer fit() loop, called once per epoch.

### Architecture Experiments

**D. GAP baseline (mAP=0.354)**
All K slots share a single pooled feature vector. Slots collapse — multi-class co-detection
rarely works because the model has no mechanism to look at different image regions.

**E. Spatial slot attention (mAP=0.376)**
Per-slot attention over the feature map. Slots specialize to different spatial regions,
enabling true multi-class co-detection. val mIoU improved from 0.354 → 0.521.

### Loss Experiments

**F. Class weights (negative result)**
Tried boosting minority classes with weights [1.0, 2.0, 2.0, 0.1] (person, car, dog, bg).
The low background weight (0.1) reduced the penalty for background predictions, increasing
false positives. mAP dropped from 0.354 → 0.259. Reverted.

**G. Focal loss gamma=2.0 (mAP=0.398, best result)**
Focal loss naturally handles class imbalance without manual weight tuning.
All three classes improved, with car gaining the most (+13% relative).

**H. Focal loss gamma=3.0 (mAP=0.371, worse)**
Higher gamma focuses too aggressively on hard examples, destabilizing overall learning.
All classes regressed. Reverted to gamma=2.0.

**I. Aggressive scale augmentation aug_scale_min=0.40 (mAP=0.370, worse)**
Exposing the model to very small crops was intended to improve small-object (dog) detection.
However, the aggressive cropping hurt localization accuracy for person and car.
Default scale_min=0.60 was better balanced.

### Inference / Video Experiments

**J. EMA per class vs. per slot**
Initial EMA smoothing for video was keyed by predicted class. When two slots both predicted
"person", the second overwrote the first in the dictionary, causing one detection to
disappear. Fixed by keying EMA state by slot index instead.

**K. conf_thresh=0.15 (too noisy)**
Lowering the confidence threshold improved recall on dogs but caused all 3 slots to activate
constantly, even in empty-background frames.
Solution: Lower conf_thresh + raise bg_gate to compensate.

**L. Background gate (bg_gate)**
Added a secondary filter: suppress any slot whose background probability exceeds bg_gate,
regardless of the best foreground class score. Final setting: bg_gate=0.5.

## 7. Results

### Quantitative (test set, conf_thresh=0.25)

| Model                              | person | car   | dog   | mAP@0.5 |
|------------------------------------|--------|-------|-------|---------|
| GAP baseline (no pretrained)       | —      | —     | —     | 0.150   |
| GAP + pretrained + ImageNet norm   | ~0.39  | ~0.20 | ~0.31 | 0.354   |
| Spatial attention (CE loss)        | 0.446  | 0.200 | 0.472 | 0.376   |
| Spatial attention + focal γ=2.0   | 0.476  | 0.225 | 0.493 | 0.398   |
| Spatial attention + focal γ=3.0   | 0.446  | 0.188 | 0.478 | 0.371   |
| Spatial attention + focal + scale40| 0.425  | 0.203 | 0.482 | 0.370   |

**Best model: Spatial attention + focal loss (gamma=2.0)**
Checkpoint: checkpoints/part3_spatial/spatial_attn_focal/best.pth

### Qualitative Observations (video inference)
- Person detection: reliable, stable boxes even in crowded scenes
- Dog detection: good when dogs occupy a significant portion of the frame; misses small/distant dogs
- Car detection: detects cars but with lower confidence than person; limited by training data scarcity

### Final Inference Settings
- conf_thresh=0.20, bg_gate=0.5, ema_alpha=0.4

## 8. Failure Analysis

**Car under-detection:**
With only 1,163 training instances vs. 9,606 for person, the model assigns lower confidence
to cars. Even focal loss could only partially compensate for this 8:1 imbalance ratio.
A larger, class-balanced dataset would be the primary remedy.

**Small dog misses:**
Dogs that occupy a small portion of the frame are often missed. The spatial attention mechanism
helps localize dogs when they are visible, but MobileNetV3-Small's receptive field and
feature resolution limit detection of small objects. A feature pyramid network (FPN) would
address this in future work.

**Slot count fixed at K=3:**
If an image contains more than 3 objects of the target classes, excess objects are always
missed. The fixed-slot design is a fundamental constraint of the approach.

---

## 9. Conclusion

The spatial slot attention architecture significantly outperformed the GAP baseline across
all metrics, confirming that per-slot spatial feature decoupling is necessary for reliable
multi-class co-detection. The combination of spatial attention + focal loss (gamma=2.0)
achieved the best mAP@0.5 of 0.398, representing a +165% improvement over the initial
untrained baseline (0.150) and a +12% improvement over the fully-debugged GAP baseline (0.354).

The most impactful engineering decisions in order of effect:
1. Enabling pretrained ImageNet weights (+135% mAP relative to random init)
2. Spatial slot attention replacing GAP (+6% mAP, enabled multi-class co-detection)
3. Focal loss replacing standard cross-entropy (+6% mAP, improved minority classes)
4. Correct ImageNet normalization in both training and inference (qualitative fix)
5. Per-slot EMA smoothing in video inference (fixed single-class collapse in video)
